# 架构概览

X-Store 采用经典的前后端分离架构，后端提供 RESTful API，前端通过 HTTP 请求与后端交互。

│  :3000       │     │  :5173      │     │  :3001       │

## 分层架构

后端采用 **四层架构**，职责清晰：

| 层级 | 目录 | 职责 |
|------|------|------|
| **Handler** | `internal/handler/` | 接收 HTTP 请求，参数校验，调用 Service |
| **Service** | `internal/service/` | 业务逻辑，事务处理，跨模块调用 |
| **Repo** | `internal/repo/` | 数据访问层，GORM 操作 |
| **Model** | `internal/model/` | 数据模型定义，对应数据库表 |

### 请求流转

```
HTTP Request
  → Router (路由匹配)
    → Middleware (认证/限流/签名)
      → Handler (参数解析)
        → Service (业务逻辑)
          → Repo (数据库操作)
            → Model (数据结构)
```

## 核心模块

### 用户系统

- 用户名 + 密码注册登录
- GitHub / Google OAuth 第三方登录
- JWT Token 认证
- 角色区分：`buyer`（买家）/ `admin`（管理员）

### 商品系统

- 分类管理（树形结构）
- 商品 CRUD + 搜索
- 富文本商品详情
- 标签、封面图、原价/现价

### 订单系统

- 订单创建 → 支付 → 发货（自动/手动）
- 卡密自动分配
- 订单状态机：待支付 → 已支付 → 已发货 → 已完成

### 支付系统

- 统一 `Provider` 接口抽象
- 10 种支付方式（支付宝/微信/Stripe/PayPal 等）
- 统一回调验签处理

### 安全机制

- JWT 身份认证
- 防重放攻击（nonce + timestamp + Redis）
- 接口限流（令牌桶算法）
- 管理员权限校验
